API Carteira Digital
Projeto backend simulando o motor de uma carteira digital. O sistema permite o cadastro de usuários, consulta de saldo e transferências seguras entre contas, validando regras de negócio como saldo suficiente e contas inexistentes.

Tecnologias Utilizadas:

Java 17

Spring Boot (Spring Web)

Spring Data JPA (Mapeamento Objeto-Relacional)

H2 Database (Banco de dados em memória)
